# Međasi Futsal Liga — v2

Novi sajt lige: utakmice uživo, tabela, ekipe i igrači, vijesti, galerija, chat, administracija.

- **Frontend:** čisti HTML/CSS/JS (ES moduli), bez build koraka. Radi na bilo kom statičkom hostingu.
- **Backend:** novi Supabase projekat (`supabase/schema.sql`): baza, RLS, auth, realtime.

## Podešavanje
Pogledaj `README.md` u pripremljenom ZIP-u za kompletne korake. Prije korištenja treba podesiti URL i anon ključ u `js/config.js` iz novog Supabase projekta. Nikad ne stavljaj `service_role` ključ u frontend.
